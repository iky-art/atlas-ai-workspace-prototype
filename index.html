ATLAS
AI Workspace

An experimental AI workspace interface by Orbit Studio — sessions, a simulated assistant, and a full set of workspace tools, running entirely on this device. No backend, no external AI, nothing sent anywhere.

What's inside
Simulated Workspace Chat

Local, keyword-matched responses with a typing effect — no external AI connected.

Sessions

Create, rename, and switch between sessions — saved on this device only.

Command Palette

Press Ctrl+K for quick actions — new session, search, theme, settings.

Photo Attachments Prototype

Image attachment UI is in place — upload handling isn't wired up yet.

Text-to-Speech Prototype

Read-aloud control is on every response — playback isn't implemented yet.

Local-first

Everything — sessions, messages, preferences — stays in this browser.

Push to GitHub

A guided repo-generation flow, step by step — a demo of the experience, not a live sync.
